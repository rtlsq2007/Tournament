## 프로젝트 개요

## 참고 프로젝트(team-splitter) 분석 요약
- 이름은 tournament지만 실제로는 **"인원을 팀으로 나누는 도구"**(토너먼트 앱 아님). 토너먼트의 전 단계만 존재.
- 스택: React 19 + Vite 8, 순수 CSS, localStorage, html2canvas(결과 PNG 저장).
- 구현: 참가자 입력/선택, ★1~5 티어, 그룹 저장·불러오기, 팀 나누기(랜덤 / 티어 지그재그 밸런싱), 결과 카드.
- **재활용 대상**: `src/utils/balancer.js`의 밸런싱 알고리즘.
- 발견된 버그(참고용): `App.jsx`가 정의되지 않은 `<TeamSettings>` 사용 → 실행 시 크래시. CSS 변수 `--primary`/`--radius` 미정의.

## 핵심 결정 로그 (2026-06-22)
1. **참가자 역할**: A) 보기 전용부터 개발. B(셀프 점수 보고)·C(다중 운영자/코트별 입력)는 **추후 확장**. 설계는 확장 쉽게.
2. **규모**: 소규모, 참가자 **~40명 내외**. → 몇 초 간격 **폴링**만으로 실시간 충분. 푸시 인프라 불필요.
3. **조 구성**: **자동 페어링(티어 밸런싱)** 과 **이름 직접 입력**, 둘 다 지원. 단식·복식·혼복 모두 동일 방식.
4. **대회 포맷**: 4종 모두 구현 후 운영자가 선택 — 싱글 엘리미네이션 / 조별리그→본선토너먼트 / 전체 풀리그 / 게임데이 로테이션.
5. **아키텍처(접근 ①)**: Cloudflare **Pages + D1(SQLite) + 폴링**.
   - 대회 상태 전체를 `tournaments(id, admin_token, data_json, updated_at)` 한 칸에 JSON으로 저장(마이그레이션 부담 없이 데이터 모델 자유 변경).
   - 운영자용 비밀 토큰 링크 / 참가자용 공개 보기 링크(+QR) 분리.

## 추가 요구사항
- **진행 상황 가시성**: 운영자 화면과 참가자 화면 **둘 다** 대회 진행 상황(현재 라운드, 진행/완료 경기, 다음 경기, 순위표 등)을 한눈에 보기 편하게 구성. → 섹션 4에서 설계.

## 추가 결정 (2026-06-22)
- **경기 방식 설정화**: `bestOf`(단판 / 3판2선승 / 5판3선승 등)를 대회 설정으로 선택 가능. 경기 데이터는 세트별 점수 `games: [{a,b}]` 저장, 과반 세트 승리 팀이 승자.
- **복식·혼복 자동 밸런싱 세부 로직**: 전 기능 완성 후 별도 논의(현재 설계안 유지하며 추후 조정).

## 1차 포함 추가 기능 (확정, 2026-06-22)
- **결과 수정·되돌리기**: 완료 경기 점수 수정 시 `recompute`로 하류 대진·순위 자동 재계산.
- **참가자 일괄 입력 + 체크인**: 줄단위/CSV 일괄 등록 + `checkedIn`으로 출석 인원만 대진 생성.
- **다크모드 + 공유 버튼**: 다크 토글(참고 CSS 재활용) + 링크 복사/QR.
- **전광판/현황판 모드** `/t/:id/board`: TV용 코트별 현재경기 大화면.
